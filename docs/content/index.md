# callscore

Analyst rating performance platform: it ingests analyst rating calls on
securities, tracks what the security did afterwards, and scores each analyst's
track record.

This site covers setup, architecture, measured performance and the generated
API reference. The original UI mockup and build plan live under
[Design](design/index.md).
